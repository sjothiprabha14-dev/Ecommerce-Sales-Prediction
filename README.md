# 🛒 Ecommerce Sales Prediction Using Machine Learning

A web-based machine learning application developed using **Python**, **Flask**, and **Scikit-learn** to predict ecommerce sales based on input features such as quantity, unit price, and discount. The application provides quick and accurate sales predictions through an interactive web interface.

---

## 📌 Project Overview

This project uses a **Linear Regression** model to estimate ecommerce sales based on customer purchase information. The model is trained on historical sales data and deployed using Flask.

---

## 🚀 Features

- Predicts ecommerce sales using a trained machine learning model.
- User-friendly web interface.
- Fast prediction with Flask backend.
- Pre-trained Linear Regression model.
- Simple and lightweight application.
